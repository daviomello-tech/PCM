# BINTECH — PCM Didático

Aplicativo de gestão da manutenção com foco em **inspeção por ultrassom**.

## Abrir

Baixe o repositório e abra `index.html`, mantendo a pasta `assets` ao lado. O arquivo `Bincorp_PCM.html` contém a mesma aplicação, preservando o caminho anterior.

## Recursos

- Cadastro inicial de 15 equipamentos, componentes e gestão em lote.
- Solicitações de serviço e ordens vinculadas.
- Planejamento, procedimento, PT, checklist e resultados por ponto.
- Validação, encerramento, histórico, exportação PDF/CSV e backup JSON.
- Identidade visual BINTECH e layout responsivo.

## Dados

Armazenamento local no navegador, chave `pcm-didatico-v1`. Faça backup antes de mudar de endereço ou navegador. Não há login Google, sincronização ou backend conectado. O envio ao GitHub não ativa GitHub Pages automaticamente.

Os exemplos são fictícios. MOT-001, MOT-002 e MOT-003 aguardam identificação de motores reais. A aprovação de PT é apenas registro didático, sem autenticação ou assinatura digital.
